Submission FAQ

Before you upload.

Practical answers on samples, file formats, confidentiality and GDPR.

Do I need to send a physical product?
No for Bronze and Silver. For Gold, CNP requests samples only after the experimental protocol, quantity and shipping conditions are confirmed.
Which file formats can I upload?
The portal accepts common office, image and archive formats. Larger files can be shared through a secure cloud link in the notes.
How does CNP protect personal data under the GDPR?
CNP uses submission data for the stated assessment purpose, limits collection to what is necessary, restricts access and retains information only for the period described in the applicable notice. Read the Data Protection Notice and remove unnecessary personal data before upload.
Should confidential formula data be uploaded?
Only the information required for the assessment should be shared. The production portal should use restricted Drive access and a final confidentiality/data-processing framework before commercial launch.

CNP is an independent scientific assessment framework in development. It does not replace legal cosmetic compliance, public-authority review or accredited certification.
